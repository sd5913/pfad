## Three-to-five-minute evidence check

Use the existing fictional Ada/Bo example and its prepared trace. Paper labels
or a static copy are sufficient; do not make a new model call for this exercise.

1. **Predict:** Ada asks, "If I find the original later, should I keep both?"
   Identify the earlier message needed to understand "the original."
2. **Locate:** point separately to the selected history in the next request and
   the cited handbook passage supporting the policy answer. A database row,
   a nearest vector and a source-backed answer prove different things.
3. **Check isolation:** inspect the prepared Bo request. What would demonstrate
   that Ada's conversation did not enter it? Use the actual request evidence,
   not just a changed profile label.
4. **Challenge:** suppose a saved message contains an out-of-date fee. Which
   current source would you check, and how should the answer reveal uncertainty?
   Do not change the real handbook fixture or present the invented fee as policy.
5. **Explain a boundary:** the bot may read a cited source and speak an answer.
   It has not been given permission to submit a replacement request, send a
   message or change an account. Draw where approval would be needed before
   adding such a tool.

If a trace is unavailable, label the exercise a paper scenario. Do not describe
a hypothetical isolation or restart check as a passed runtime test. The
existing README and REHEARSAL guide retain their live checks and fallbacks.
